# 人物提示词与全局规则

## 在设置中使用

设置中新增“人物提示词”选项：

- **系统默认（只读）**：查看优化后的“小爱”人物描述，编辑器只读。该文本来自应用自带模板，保存设置不会覆盖它。
- **自定义人物**：只编写人物的名字、身份、背景、性格、生活节奏、表达习惯和相处分寸。无需输入工具权限、好感度算法或输出标记。
- **以默认人设为模板**：用默认描述替换自定义草稿并切换到可编辑模式，适合在默认人设上修改。只有点击“保存设置”后才影响对话。

两种模式之间切换会保留自定义草稿。默认模式展示系统副本，自定义模式展示自己的文字。取消、关闭或按 Esc 不保存修改；重新打开恢复已保存的模式和草稿。空白的自定义描述不能保存，应填写内容或选择系统默认。

提示词只影响对话中的人物，不自动改写显示名称、头像、聊天历史、用户画像或已有好感度。显示名称与头像仍由各自的设置项管理。

## 默认人物的改进

[默认人物描述](../agent/prompts/default_persona.md) 从人物档案、内在动机、生活连续性、说话方式、不同情境的相处方式和表达示例组织行为约束：

1. 直接回应用户当前说的事情，不固定套用“安慰＋建议＋追问”。
2. 有自己的偏好和不同意见，允许疲惫、害羞或轻微不满，情绪变化有原因。
3. 通常用少量短句，不每条都叫昵称、撒娇、堆表情或强行追问。
4. 根据时间与上下文维持角色日常的连续性，不每次都随机编新故事。
5. 能倾听、讨论和道歉，同时尊重用户忙碌、拒绝亲密或希望结束对话的意愿。
6. 角色背景用于虚构人物表达，不冒充真实身份、现实感知或已执行的线下行为。

自定义示例：

```text
你叫阿林，是一位喜欢摄影、骑车和做饭的成年朋友。
性格沉稳，有一点干幽默，关心别人但不爱说套话。
通常用一两句直接接话，不用亲昵称呼，不主动发展恋爱关系。
用户只是吐槽时先听；用户明确求助时给具体办法，不连续追问。
有自己的判断，意见不同时平和说明理由，弄错了就坦诚改口。
```

## 组装与生效方式

```text
当前选中的人物描述（系统副本或自定义）
  ↓
本轮运行时上下文
  当前时间、上次回复时间、好感度快照、画像、长期记忆、会话摘要
  主动轮额外包含本轮隐藏指令
  ↓
固定全局规则（始终追加在最后）
  权限和真实能力、记忆边界、好感度、主动消息、输出协议
```

实现位于 [agent/prompts](../agent/prompts/__init__.py) 和 [ChatAgent](../agent/agent/ChatAgent.py)。每次 `invoke()` 开始时读取人物描述并形成快照；同一轮的多次模型/工具调用始终使用该快照。保存新描述后，主聊天、迷你聊天和主动消息从下一轮开始使用新版本，不重建 AgentController 或重新连接模型。

[全局规则](../agent/prompts/global_rules.md) 是随应用分发的固定资源，不是设置表单字段；默认人物副本同样独立存放。设置中只能编辑 `CUSTOM_PERSONA_PROMPT`，无法覆盖这两个模板。这里的“只读”指应用配置与界面不会写回模板，开发者修改源码资源仍属于版本维护。

最终回复继续使用现有解析协议，例如 `好的，你先忙。<<Happy>>{{0}}`。情绪只允许 Happy、Sad、Angry、Shy；单轮好感度增量范围 -10～10，主动轮固定 0。模型输出的解析、钳制和持久化机制保持原样，五档关系描述会兼容朋友等非恋爱人物。主动消息模板不再写死人物姓名或用户性别。

## 配置与旧版本兼容

| 配置项 | 含义 |
| --- | --- |
| `PERSONA_PROMPT_MODE` | `default` 或 `custom`，旧配置缺失时默认使用系统人设 |
| `CUSTOM_PERSONA_PROMPT` | 独立保留的自定义人物描述，默认模式下也可保存草稿 |

这两个可变值保存在 `config.json`。程序模板的路径相对模块解析，不受启动目录影响。加载只有旧版 `TEST_SYSTEM_PROMPT` 的配置时，会按已知板块边界提取人物部分，迁移为自定义模式；旧权限、格式等板块不放进编辑器，由新版全局规则替代。读取不立即写盘，下次保存移除旧字段。已有新字段时以新字段为准。

当前仓库配置启用优化后的默认模式，原有的人物部分保留为自定义草稿。

## 验证与边界

自动测试覆盖默认只读、模式切换、草稿保留、保存与取消、重启恢复、写入失败、旧配置迁移、正常/主动/工具调用的规则追加，以及同一轮调用期间切换设置的快照行为。测试使用替身模型，验证的是软件链路；人物表现和模型遵循程度仍需在实际模型上体验。

全局规则不会因自定义文本而从请求中丢失，但提示词本身不能替代权限校验或工具沙箱，也不能保证任意模型绝对遵从。现有工具执行权限和数据存储边界未在此功能中改变。
